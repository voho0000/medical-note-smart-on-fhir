## 所附論文有什麼，為何不能直接照抄

Chang 等人，[IJERPH 2022, 19, 1319 線上原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC8835337/) 的 Table 2 確有依性別區分的冠心病（CHD）、中風、重大心血管事件（MACE）模型係數，年齡是 log(age)。但文中式 (1) 是 **Harrell's C 判別力統計量**，不是輸入病人數值後算出十年風險的公式。它**沒有**糖尿病與高血壓的模型係數，亦未提供 CHD／中風逐項的完整 10 年基準存活函數及運算細節。尤其論文的男性 MACE 模型使用尿酸與腰臀比，2026-09-16 的公開五項表單卻沒有這兩欄。故不能把論文 Table 2 係數假稱為現行網站全部五項的可執行公式。[2025 年發表的論文評議](https://pmc.ncbi.nlm.nih.gov/articles/PMC12294525/)也明確指出模型類型／基準存活率的可重現性問題，以及糖尿病、高血壓模型未在 2022 年原文中報告；這是對已發表資料的限制，不表示現行官網的模型沒有另外開發。

- 從官網公開頁面確認五個模型的輸入欄位、疾病既往史的畫面處理與風險分級；官網回應的模型代號為 CHDRiskV3、DiabetesRiskV3、HypertensionRiskV3、StrokeRiskV3、MACERisk（版本欄位 4）。
- **只用合成數值**，首輪取得 388 組五項結果，另查詢 72 組（男女各 35–70 歲）高血壓年齡參考風險。第二輪依官網表單的公開 `GET token → POST allmodel` 流程，以單線程、約每秒一筆再查 248 組：88 組單變項探測、120 組隨機擬合、40 組預先保留。沒有送出或保存任何病人資料；產品運作時不呼叫官網，也不儲存或依賴權杖。第二輪官網回應的 `risk` 已是無條件捨去的整數；`populationAvg` 與 `multipleDiff` 可約束捨去前風險所在區間。

## 進一步重建：區間求解與輸出精度

前節的 177/180、185/191、282/287 是**舊係數版本**的整數配對結果，保留作為研究歷程，不能當作目前版本的驗算分數。此次將已查看的 348 組歷史案例全部明確改列校準資料，再新增 480 組主動邊界案例（第一批成功 24 組、第二批 96 組、第三批 360 組），共 **828 組合成案例、3,979 個適用疾病輸出**。已知糖尿病／高血壓的新發風險仍排除，不以不適用輸出充數。

### 差異原因與修正

1. **整數輸出是區間，不是精確連續機率。** 舊版把捨去後整數及相對倍數約束的區間中點拿來擬合，會留下足以跨過整數界線的小誤差。新版直接把每筆輸出轉成互補雙對數空間的線性不等式，用最大共同內部裕度求一組同時符合全部觀察的係數，不加入個案特判或病例查表。
2. **最後確實是無條件捨去，但它之前還有精度處理。** 主動探測每一性別／疾病的整數切換點，顯示 `risk2 = round(rawRisk × 100) / 100`、`display = trunc(risk2)` 可以解釋全部觀察；在同一函數族內，直接捨去、先保留 1 位或 3–6 位小數則無法同時符合。完全移除 `populationAvg`／`multipleDiff` 約束、只使用整數風險，仍得到相同判別結果。因此它不是「把官網的無條件捨去誤改為最後四捨五入」。這是對公開行為的推定，並非讀到官方後端程式。
3. **高血壓的比值也有取位順序。** 公開測試支持使用 `round(risk2 / populationAvg × 100) / 100`，再依 `<0.75`、`>1.25` 分級。不能改用最後的整數風險作分子，也不能完全略過兩位小數的風險與倍數取位。
4. **收縮壓是整數輸入。** 公開後端拒絕小數 SBP；第一批邊界探測因此安全停止，已成功取得的 24 筆仍保留，沒有假裝整批完成。後續改用腰圍、血糖或體重等可接受小數的欄位定位界線。本地對需要 SBP 的模型也不默默四捨五入使用者輸入。

新版校準結果：**3,979/3,979 整數風險相同，3,979/3,979 分級相同**；原先那 180 個結果，現在兩項都是 **180/180**。以上是校準內吻合，不是獨立驗證。`scripts/hpa/artifacts/frozen-candidate-v1-2026-09-16.json` 保存固定前的完整係數與統計。另以固定模型後才送出的全新合成資料驗證，結果紀錄在後續驗證報告。

係數採可重現的區間推定值，不硬套論文四位小數的係數：雖然部分吻合，直接將尚不精確的估計值取到論文位數並不能保證正確。相對倍數約束另保留分子風險的 ±0.005 不確定度，避免把倍數誤當成未取位風險的精確量測。各年齡性別的公開族群平均在採樣期間未觀察到變動。

Fable 5.1 經 Claude Code CLI 做過**方法層級**的獨立檢查，提醒倍數來源、輸入型別與有限樣本不能證明普遍等價；它沒有取得官方程式，也未替代本地回歸測試。新版照此將數值取位假設做整數輸出獨立檢查，並保留新驗證樣本與候選係數的 SHA-256 對應；所有適用結果都納入計分，沒有只報容易配對的子集。

### 關鍵缺漏：BMI 在代入公式前先取四位小數

第三版新驗證仍有一筆女性高血壓不同（本地 23%、官網 22%），新案例成績為 **2,560/2,561 整數風險、2,561/2,561 分級相同**；兩組重複基準另為 10/10。更靠近分級界線的 1,440 個輸出全部吻合。原始成績保存在 `validation-v3-2026-09-16.json`。

因此另開高血壓專用的自適應探測，原計畫上限 60 輪，**實際完成 49 輪、98 組後自動停止**：連續、不取位的 BMI 假設已無法同時符合全部觀察。這不是只把某個係數再多留幾位就能解決的問題；將求解器的不等式尺度放大 1,000,000 倍以排除容許誤差後，仍有矛盾。此批維持 `complete: false` 並記錄停止原因，98 組成功回應全部保留校準，不假稱 60 輪完成。

比較 BMI 取 0–8 位、BMI 無條件捨去四位、Float32 輸入／BMI／風險等候選運算後，在已測候選中，**只有 BMI 四捨五入到四位小數**能解釋全部 **13,091 個適用輸出**。不取位的 BMI 有 8 個整數風險不一致；直接捨去四位亦不能解釋全部案例。比較紀錄為 `scripts/hpa/artifacts/bmi-precision-audit-2026-09-16.json`。公開表單的單次合成型別驗證亦回報體重為 Java `Double`；這次輸入驗證沒有風險輸出，不列入配對分數。

目前產品的運算順序為：

```text
BMI = round(體重 / (身高 / 100)², 4)
rawRisk = 100 × [1 − exp(−exp(線性預測值))]
risk2 = round(rawRisk, 2)
顯示百分比 = trunc(risk2)
高血壓相對倍數 = round(risk2 / 同性別同年齡族群平均, 2)
```

BMI 的取位用於四個含 BMI 的模型（男女糖尿病、高血壓）。**最後顯示仍是無條件捨去**；不能把 BMI 的四位、風險的兩位和最後的整數捨去混為同一步。這是公開行為支持的重建運算，不代表讀到了官方後端原始碼。

複查亦指出需要保留的限制：

- 固定 JSON 保存的是特徵名稱與係數，並非完整可執行規格；中心化常數、年齡轉換、風險連結與族群平均仍須連同產品 TypeScript 一起保存。現有測試會核對驗證檔內的候選雜湊字串，但沒有自動重算固定係數檔雜湊或逐項比較產品係數；此次另已實際核對十個係數向量完全一致。
- 四捨五入作用於實際的 IEEE 雙精度數值，不是任意精度十進位算術。例如 `70 / (160 / 100)²` 在目前運算次序下為 `27.343749999999996`，BMI 取四位得 `27.3437`；若先以整數形式運算，可得 `27.3438`。已本地確認此差異，但**尚無這個中點造成官方顯示不同的證據**，故未擅加 epsilon 或改動已驗證運算。這也是有限案例 100% 不能證明全部連續輸入一致的原因之一。
- 該四檔複查不包含前端呈現及缺值／診斷門檻測試；這些路徑另由已通過的 `hpa-risk-results.test.tsx`、`hpa-risk.test.ts` 涵蓋，不冒稱 Fable 本次也讀過它們。係數可行區間與求解裕度有限，尤其極近整數取位點仍須保留不確定性。

## 安全邊界

- 僅在所查詢的合成案例數值範圍內顯示近似百分比：年齡 35–70、身高 150–190 cm、體重 45–115 kg、腰圍 60–125 cm、收縮壓 90–139 mmHg、空腹血糖 70–125 mg/dL、總膽固醇 120–300、三酸甘油酯 45–400、LDL-C 45–220、HDL-C 25–95 mg/dL；每項結果只檢查其實際用到的欄位。這些是**重建版的驗算邊界**，不是官方輸入限制或生理正常值。
- 已知糖尿病／高血壓、空腹血糖 ≥126 mg/dL／收縮壓 ≥140 mmHg 時，不顯示該病新發風險。2026-09-16 再查核[官網五項表單](https://cdrc.hpa.gov.tw/v4/hra-allmodel.jsp?openservice=true)的顯示判斷：`sbp >= 140`、`glu >= 126` 會隱藏對應百分比；已知病史優先於數值提示。本地將數值門檻獨立標為 `review`（需核對血壓／血糖），不再與 `existing`（已有病史）混用；單次測量不當成確診。加入官網五項表單未要求的「既往冠心病或中風」問題；回答有時不顯示三項心血管新發風險。未回答病史不推定「無」。
- 空腹血糖只從明確的 fasting LOINC `1558-6` 自動帶入，不將任意血糖誤作空腹值；腰圍使用 `8280-0` 或符合單位的名稱。依使用者 2026-09-16 明確要求，自動帶入的相關檢驗相差超過 7 天時**僅顯示日期提醒，不阻擋任何適用風險結果**；仍保留來源日期供核對。既有疾病、診斷門檻、缺值與驗算範圍判斷不變。
- 此結果不適用於診斷、處方或取代官網；官網更新模型後須重新驗算。製作日期與模型版本應一併保留在審查紀錄。
