# 影像類文字報告格式化盤點

## 範圍與來源

唯讀掃描相鄰 NHI-FHIR-BRIDGE 的 `fixtures/local/patients/*.json` 與 `fixtures/local/nhi-raw-fixture.json`，擷取有 `order_NAME` 與 `desc` 的原始明細。不納入衍生 bundle、golden digest、影像二進位資料；原始快照與病人資料可能重複，因此以下是記錄數，不是獨立檢查或病人數。

- 15 份來源檔、1,088 筆明細。
- 808 筆有文字，280 筆空白。
- 429 種不同文字（精確字串去重；換行、全半形不同仍各計一次）。
- 影像類來源同時包含心電圖、內視鏡、病理等報告。
- 本文件與合成測試不收錄病患報告、識別資料或來源檔名。

## 呈現策略

| 原文形式 | 處理 |
| --- | --- |
| 所有類型 | 還原 CR、CRLF 換行；保留未知原文；長橫線呈現為分隔線 |
| X 光、CT、MR | 已知標題、編號分段；長敘述依明確句界換行，保留小數與單位 |
| 腎臟超音波 | 左右腎尺寸、The/There 描述分行，Impression 的點號條列分開 |
| DOPPLER & ECHOCARDIOGRAPHIC REPORT 模板 | 原欄名與數值／參考範圍左右排列；瓣膜段落分開；結論逐項呈現；摘要保持原文 |
| 其他心超模板 | 辨識既有獨立標題，其餘保留原始行；不套用不同院所的欄位假設 |
| 頸動脈超音波 | 區分 B-mode、Doppler、interpretation；數據區保留等寬原始欄位與空白，可水平捲動，不推算欄位 |
| 腹部超音波 | 全形冒號、器官標題、Sonar Diagnosis 分段 |
| 心電圖、Holter | CR／多空白行界與編號條列 |
| 病理、核醫、內視鏡 | 大寫標題、全形冒號及既有段落／條列 |

心超空白測量直接留白；原有參考範圍與單位照原文保留，不加入「未填」或其他原文沒有的報告內容。原始 FHIR 資料不修改；複製與 AI 輸入使用相同段落序列，保留原有標點。這是排版處理，不生成臨床解讀。

## 驗證與限制

執行本機稽核：

```sh
node scripts/audit-report-format.mjs ../NHI-FHIR-BRIDGE/fixtures/local
```

808 筆報告全數通過非空白字元及順序相等檢查。12 筆進入心超測量模板，8 筆包含等寬數據區；376 筆使用一般文字行呈現，這些可能已有良好換行，也可能沒有足夠結構可可靠辨識。通過內容保全不代表每筆都已轉成結構化表格。

合成案例涵蓋小數、全半形單位、空白測量、瓣膜數值、結論、腎臟條列、CR、Holter、核醫、病理及頸動脈表格。實際瀏覽器以正式元件與編譯後 CSS，在 320、390、430、768、1024、1440 px、淺色／深色模式檢查無頁面水平溢出；此為獨立元件檢查，非登入後全流程測試。

仍無法從已被上游刪除的換行還原所有語意邊界；未知模板保持可讀原文，不能保證未來所有院所格式都能轉成欄位。新增模板應以合成案例測試，並重跑本機全量內容保全稽核。

## 胃鏡報告補充

補上 Esophagus、Stomach、Duodenum、Others 與技術員標題；HP FAST 的行內陰性條列及無空格圓點皆可辨識。HP FAST 胃鏡模板會將器官內容的句子及切片標記分行，統一段落內縮排。對已確認的 `GU-S / GASTRITIS / GERD, LA GRADE A–D / DUODENUM POLYP` 連續診斷模板恢復行界；未知診斷文字保持原樣，不任意拆開大寫詞語。合成回歸案例同時檢查整段與 CR 換行版本。
