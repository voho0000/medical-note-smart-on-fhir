# PREVENT ASCVD calculator

`features/medical-calculator/calculators/prevent.ts` is the single implementation of the base PREVENT ASCVD probability equations. The medical calculator and dyslipidemia CDSS share its definition, input resolver, patient input store and panel. CDSS's `applyPreventReading` only transfers numeric outputs and provenance; clinical guideline bands and treatment targets remain in the care pack. No PCE/WHO substitution and no risk formula in CDSS.

The published March 2024 correction (https://www.ahajournals.org/doi/10.1161/CIR.0000000000001230) changes the SDI source years to 2015–2019; it does not change the base model coefficients.

Primary source: Khan SS et al. Development and Validation of the American Heart Association PREVENT Equations. Circulation. 2024;149:430–449. https://pmc.ncbi.nlm.nih.gov/articles/PMC10910659/ (doi:10.1161/CIRCULATIONAHA.123.067626), Supplemental Table S12, base ASCVD models. Use the ASCVD endpoint, not total CVD or HF probability.

The numeric coefficient arrays retain the published precision represented in MIT-licensed `preventr` 0.12.0, `R/sysdata.rda` objects `base_10yr` and `base_30yr`, female_ascvd/male_ascvd columns. Source revision: https://github.com/martingmayer/preventr/tree/ebe2ac15c38569c3bdaf871c4853b6eeff77b039 . Attribution is in `third-party/preventr-LICENSE.md`. This is an independent implementation from published research and these coefficients; it does not use the AHA's separately licensed calculator code. Coefficient array order matches Table S12; the 30-year model adds centered age squared after age. HDL and age×HDL are per **0.3 mmol/L**. Cholesterol conversion uses 38.67 mg/dL per mmol/L as in the paper. Probabilities retain full precision for downstream classification; display is one decimal.

Validation includes the paper's example: woman aged 50, TC 240, HDL 55, treated SBP 160, BMI 35, eGFR 90, no diabetes or statin. Nonsmoker: 10-year ASCVD 3.6%, 30-year about 20%; smoker: 6.0% and about 26%. Tests also cover missing/invalid inputs, both sex models, 30-year age boundary, input units, CVD exclusion, input changes invalidating old results and module output transport.

Eligibility follows https://professional.heart.org/en/guidelines-and-statements/prevent-calculator : age 30–79; 30-year output only 30–59; no known CVD including HF. Confirm every binary input. No absent diagnosis/medication is assumed negative. Numeric ranges: TC 130–320, HDL 20–100 mg/dL, SBP 90–200 mmHg, eGFR 15–140 mL/min/1.73m², BMI 18.5–39.9 kg/m². Out-of-range values produce no probability. Known ASCVD/HF in the imported profile blocks computation even if a previous manual answer said no. BMI is retained for eligibility although its coefficient is zero in the ASCVD model.

This is the base model only: no UACR/HbA1c/SDI extension, no Taiwan recalibration. Each input retains its own date; the review panel asks clinicians to confirm that the measurements and current medications represent this assessment. Manual changes are encrypted per patient within the browser session, shared across the two surfaces, and can be cleared back to record values. No chart write or external calculator request is made.

For the beta dyslipidemia review, use the paired core branch `codex/dyslipidemia-complete` and app branch `codex/dyslipidemia-cdss`. Run `npm run dev:lipid -- /path/to/mediprisma-personalization` to build and overlay the paired local core packages, then open http://127.0.0.1:3017/dev-lipid-review . The app pins the two paired local package archives in vendor/cdss, including lockfile integrity hashes. Normal installation therefore gets these reviewed rules without requiring a registry release. Publishing remains a separate release step. Synthetic review routes return 404 in production. HF remains the default enabled pack; dyslipidemia is an optional Beta.
