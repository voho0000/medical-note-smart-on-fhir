## 1. 產品定義（先對齊，再談各科）

### 1.1 兩個版本，一個骨架

```
輸入：科別（必要）＋ 初診/複診（必要）＋ PROM（可選）＋ 健康存摺 bundle

┌ 第 1 層　本科主軸 ────────────────────────────────┐
│ 複診：本科上次就診後發生了什麼（上次檢查摘要、用藥變動、    │
│       追蹤中的指標）                                       │
│ 初診：跟本科相關的重點（相關診斷、相關檢查最近一次、        │
│       相關用藥、紅線）                                     │
├ 第 2 層　相關科別最近檢查 ──────────────────────────┤
│ 由科別表單定義的「相關科別」清單驅動；只列「最近一次」       │
├ 第 3 層　全人問題清單＋負責院所／科別 ────────────────┤
│ 每個問題掛「最近在哪家院所／哪科處理」，供最後完整檢視        │
├ 第 4 層　資料涵蓋邊界 ──────────────────────────────┤
│ 確定性計算：資料起訖、院所數、各類資源計數（零 AI）        │
└──────────────────────────────────────────────────────┘
```

**兩版差異只在第 1 層。** 第 2–4 層共用。這樣各科表單只需要多定義「初診時第 1 層要什麼」，不用整套填兩次。

### 1.2 資料脈絡的限制（各科填表前必須知道）

健康存摺／醫雲能給的是：健保申報的**就醫紀錄、診斷碼、處方、檢驗值（部分院所有上傳）、檢查報告文字（影像、心超、內視鏡、病理，部分）、出院病摘、處置碼**。

**沒有的**：院內癌登分期、護理紀錄、門診 SOAP 全文、自費項目、影像本身、多數院所的問卷。

所以各科填「我要看 X」時，要先過一關：**X 在跨院資料裡存在嗎？** 表單的每一欄都要求填「資料來源型別」，填不出來的項目就是 PROM 或院內系統的事。

### 1.3 「本科」與「初診」怎麼判定

| 判定 | 方式 | 備註 |
|---|---|---|
| 本科 | 科別參數（§2） | 次專科粒度：心臟內科 ≠ 心臟外科；腎臟科 ≠ 一般內科 |
| 初診／複診 | bundle 內是否有本院本科 Encounter | 跨院資料有院所＋科別碼（健保申報科別）。若無科別碼，退回「本院是否有任何就診」 |
| 本科上次就診 | 本院本科最近一次 Encounter 的日期 | 「上次之後」的時間窗以此為錨點 |

**待確認**：健保申報的科別碼粒度到哪裡？次專科（如心臟內科 vs 一般內科）在申報資料裡分得出來嗎？分不出來的話，複診判定只能到「內科」層級。

## 2. 科別參數的三個來源（優先序）

| 優先 | 來源 | 現況 | 動作 |
|---|---|---|---|
| 1 | Launcher URL 參數（醫析 / medcloud2 extension） | `parseMedcloudLaunchOptions` 已收 `site`、`ws`；**尚無科別** | 新增一個 PHI-free 的 `dept=` 碼，同樣 fail-closed。需資訊室配合 |
| 2 | 登入使用者自選（含次專科） | prompt gallery 已有 37 科 tag（`prompt-specialties.ts`） | **先做這個**：設定頁加「我的科別」，沿用同一組 tag，允許多選（一人跨兩科） |
| 3 | 人事室 table 自動判讀 | 無 | 當預設值，使用者可覆寫；只到科的粒度，次專科靠 2 |

規則：1 > 2 > 3。URL 有帶就用 URL；沒帶用使用者設定；都沒有就退回現在的通用摘要。

## 3. 各科需求表單：欄位定義

每科（含次專科）填一張。**門診與住院各一欄**，同一張表。

| 欄位 | 說明 | 範例（心臟內科） |
|---|---|---|
| A. 科別／次專科 | 對應 37 科 tag，可自加次專科 | 心臟內科 / 心衰竭 |
| B. 主軸問題範圍 | 哪些診斷算「本科的事」（ICD-10 章節或關鍵字） | I00–I99、高血壓、心衰、AF、CAD |
| C. 本科關鍵檢查 | 列出檢查名稱＋**時效窗**＋資料來源型別 | 心超（18 月）、ECG、NT-proBNP、Lipid、eGFR/K |
| D. 相關科別 | 第 2 層要拉哪些科的最近檢查 | 腎臟、新陳代謝、胸腔 |
| E. 關鍵用藥類別 | 第 1 層要突顯的藥物群 | 抗凝、抗血小板、GDMT 四柱、statin |
| F. 紅線／安全警示 | 就診前一定要跳出來的 | 抗凝＋近期出血、K > 5.5、他院已裝 device |
| G. 初診特有 | 初診第 1 層要什麼 | 他院心臟相關診斷＋最近一次心超／ECG＋目前心血管用藥 |
| H. 複診特有 | 複診第 1 層要什麼 | 上次就診後的新檢查／新用藥／他院就醫 |
| I. PROM／就醫前問卷 | 該科現有或想要的問卷 | KCCQ、NYHA 自評、症狀日誌 |
| J. 門診 vs 住院差異 | 住院版（華碩）要加減什麼 | 住院加：出院病摘、住院期間檢驗趨勢 |
| K. 排除項目 | 明確**不要**看到的 | 皮膚科用藥、牙科處置 |
| L. 填表人／日期 | | |

## 4. 各科 AI 初稿（請各科打臉）

以下只填 B–H，I–K 留給各科。**時效窗只做標註（「已 N 天，建議複驗」），不阻擋。**

### 4.1 心臟內科

- **B 主軸**：高血壓、CAD/ACS、心衰竭、AF/心律不整、瓣膜、周邊動脈疾病
- **C 關鍵檢查**：心超（LVEF、E/e'、LA、瓣膜）、ECG、Holter、心導管／冠狀動脈 CT、NT-proBNP、Lipid profile、eGFR／K／Na、HbA1c、CXR 報告
- **D 相關科**：腎臟、新陳代謝、胸腔、神經（stroke）
- **E 用藥**：抗凝（NOAC/warfarin）、抗血小板、ACEi/ARB/ARNI、β-blocker、MRA、SGLT2i、statin、利尿劑、抗心律不整
- **F 紅線**：抗凝＋近期出血／手術、K 異常、他院已放 stent／device／換瓣、QT 延長藥物並用
- **G 初診**：他院心血管診斷清單 → 最近一次心超／ECG 摘要 → 目前心血管用藥（含哪家開的）→ 紅線
- **H 複診**：上次就診後：新心超／ECG／導管、用藥變動、他院急診／住院、腎功能與 K 變化
- **可借用的 CDSS pack 規則**（只借閾值與紅線，不借摘要）：heart-failure、atrial-fibrillation、hypertension、hyperlipidemia

### 4.2 腎臟科

- **B**：CKD 各期、AKI、腎絲球疾病、透析、腎移植、電解質異常
- **C**：eGFR／Cr 趨勢（≥ 3 點）、UACR／UPCR、K／Na／Ca／P／HCO3、Hb、PTH、腎臟超音波、iPTH、25-OH-D
- **D**：心臟、新陳代謝、泌尿、風濕免疫
- **E**：RAAS 抑制劑、SGLT2i、利尿劑、磷結合劑、ESA、**腎毒性藥（NSAID、顯影劑、aminoglycoside）**
- **F**：NSAID 處方中、metformin／NOAC 未依 eGFR 調整、K > 5.5、eGFR 短期下降 > 25%
- **G 初診**：eGFR 趨勢圖＋蛋白尿 → 病因線索（DM、HTN、腎絲球）→ 腎毒性藥 → 已透析／瘻管與否
- **H 複診**：上次後 eGFR／UACR 變化、新加腎毒性藥、他院顯影劑檢查
- **可借用的 CDSS pack 規則**：ckd、dm-ckd、ckd-anemia、aki、renal-safety

### 4.3 新陳代謝科（內分泌）

- **B**：DM、甲狀腺、骨鬆、脂質、肥胖、腎上腺／腦下垂體
- **C**：HbA1c 趨勢、空腹血糖、Lipid、eGFR／UACR、眼底檢查、足部檢查、TSH／free T4、DEXA
- **D**：腎臟、心臟、眼科、家醫
- **E**：胰島素、SU、metformin、SGLT2i、GLP-1、甲狀腺藥、骨鬆藥（雙磷酸鹽、denosumab）
- **F**：SU／胰島素＋低血糖就醫紀錄、metformin＋eGFR < 30、denosumab 中斷
- **G 初診**：DM 病程（首次診斷年、併發症碼）→ HbA1c 趨勢 → 目前降糖藥（哪家開）→ 三大併發症篩檢有無（眼底／UACR／足部）
- **H 複診**：上次後 HbA1c、體重、新併發症碼、他院加藥
- **可借用的 CDSS pack 規則**：dm-ckd、taiwan-t2dm、ada-2026

### 4.4 胸腔內科

- **B**：COPD、氣喘、肺癌、ILD、肺炎、TB、睡眠呼吸中止
- **C**：肺功能（FEV1、FVC、DLCO）、CXR／胸部 CT 報告、痰培養／AFB、血氧、PSG
- **D**：心臟、感染、腫瘤、耳鼻喉
- **E**：吸入劑（LABA/LAMA/ICS）、口服類固醇、抗生素史、TB 藥
- **F**：肺結節追蹤逾期、TB 治療中斷、長期類固醇
- **G 初診**：呼吸道診斷 → 最近一次 CXR／CT 報告摘要 → 肺功能 → 吸入劑
- **H 複診**：上次後新影像報告（尤其結節大小）、急性惡化就醫、抗生素

### 4.5 腸胃肝膽科

- **B**：B/C 肝、肝硬化、HCC、消化性潰瘍、IBD、膽胰疾病、大腸息肉／癌
- **C**：AST/ALT/Bil/Alb/PLT/INR 趨勢、AFP、HBV DNA／HCV RNA、腹部超音波／CT 報告、胃鏡／大腸鏡報告、H. pylori
- **D**：腫瘤、感染、一般外科、心臟（抗凝）
- **E**：抗病毒（entecavir/TAF/DAA）、PPI、抗凝／抗血小板（內視鏡前）、NSAID
- **F**：HCC 篩檢逾期（肝硬化 > 6 月無超音波）、抗病毒中斷、抗凝＋消化道出血史
- **G 初診**：肝病診斷＋病因 → 最近一次超音波／內視鏡摘要 → 肝功能趨勢 → 抗病毒用藥
- **H 複診**：上次後新超音波／CT／AFP、內視鏡追蹤到期
- **可借用的 CDSS pack 規則**：cirrhosis

### 4.6 神經內科

- **B**：中風／TIA、癲癇、巴金森、失智、頭痛、周邊神經病變
- **C**：腦部 CT／MRI 報告、頸動脈超音波、EEG、Lipid、HbA1c、B12
- **D**：心臟（AF）、神經外科、復健、精神
- **E**：抗血小板、抗凝、抗癲癇藥（含血中濃度）、抗巴金森藥、失智藥
- **F**：AF 未抗凝＋中風史、抗癲癇藥中斷、多重鎮靜藥
- **G 初診**：神經診斷 → 最近影像報告 → 血管危險因子（BP、Lipid、DM）→ 抗栓用藥
- **H 複診**：上次後新影像、新發作就醫、用藥變動

### 4.7 骨科

- **B**：退化性關節炎、骨折、骨鬆、脊椎疾病、關節置換
- **C**：X 光／MRI 報告、DEXA、Ca／Vit D、發炎指標
- **D**：復健、風濕免疫、新陳代謝（骨鬆）、神經外科
- **E**：骨鬆藥、NSAID、抗凝（術前）、類固醇
- **F**：抗凝／抗血小板（術前停藥）、雙磷酸鹽＋牙科處置、糖尿病控制差（術前）
- **G 初診**：肌肉骨骼診斷 → 最近影像 → 已做過的手術／植入物 → 抗凝
- **H 複診**：上次後新影像、他院手術、跌倒／骨折就醫

### 4.8 家庭醫學科

- **B**：全部（本科就是全人）；主軸 = 慢性病三高＋預防保健
- **C**：BP、HbA1c、Lipid、eGFR、癌症篩檢（糞便潛血、子宮頸抹片、乳房攝影、口腔）、疫苗
- **D**：不特定，第 2 層改為「近 1 年所有科別最近一次」
- **E**：慢箋全清單、重複用藥
- **F**：多重用藥（≥ 10 種）、跨院重複同類藥、慢箋領藥中斷
- **G 初診**：慢性病清單 → 三高數值 → 跨院用藥重整 → 篩檢／疫苗缺口
- **H 複診**：上次後三高數值、新診斷碼、他院就醫與加藥
- **備註**：家醫科的「本科主軸」本身就是全人，第 1 層與第 3 層會重疊；可能第 1 層改放「篩檢缺口＋跨院用藥重整」。**待確認。**

### 4.9 腫瘤內科

- **B**：各癌別（依 ICD C 碼）、治療中／追蹤中
- **C**：病理報告、腫瘤標記（CEA、CA-199、AFP、PSA…）、CT／MRI／PET 報告、CBC／肝腎功能（化療前）
- **D**：外科、放腫、血液、緩和
- **E**：化療／標靶／免疫治療（健保申報可見）、止吐、止痛（鴉片類）、G-CSF
- **F**：化療＋嗜中性球低、免疫治療＋甲狀腺／肝功能異常、鴉片類跨院重複
- **G 初診**：癌別＋診斷日（首次 C 碼）→ 已做治療（手術／化療／放療處置碼）→ 最近影像／病理 → 腫瘤標記趨勢
- **H 複診**：上次後新影像／標記、他院急診（發燒、疼痛）
- **限制**：無癌登分期，**不要**從病摘硬撈 TNM

### 4.10 一般外科

- **B**：疝氣、膽囊、乳房、甲狀腺、大腸直腸、肝膽胰腫瘤
- **C**：影像報告、病理、術前檢驗（CBC、PT/aPTT、肝腎）、內視鏡
- **D**：腸胃、腫瘤、心臟（術前風險）、麻醉
- **E**：抗凝／抗血小板、糖尿病藥、類固醇、免疫抑制劑
- **F**：抗凝未停、HbA1c > 9、他院已開過刀（同部位）

## 5. 從零設計的技術骨架（不沿用現行摘要）

**輸出模型**：四層各自是獨立的結構化區塊，UI 擁有排版權；每個主張帶可稽核的來源（資源型別＋院所＋日期）。

| 層 | 產生方式 | 輸入 |
|---|---|---|
| 1 本科主軸 | AI，prompt 由該科表單（B–H）序列化而成 | bundle 內符合 B 範圍的診斷、C 清單的檢查、E 類別的用藥、F 紅線規則 |
| 2 相關科最近檢查 | 半確定性：app 依 D 清單挑出各科最近一次檢查，AI 只寫一句摘要 | D 相關科別、報告文字 |
| 3 問題清單＋負責院所 | AI 彙整，app 附掛院所／科別 | 全部資料 |
| 4 資料涵蓋 | 純確定性 | bundle 統計 |

**表單即設定**：各科填完的 B–K 直接成為該科的 config（可以是 JSON，也可以是 personalization repo 的 pack）。新增一科＝新增一份 config，不改程式。

**兩版的差異只在第 1 層的 prompt 模板**（G 初診模板 vs H 複診模板），其餘三層共用。

**驗收標準**（R7）：對 pilot 病人，本科 C 清單中 bundle 內存在的檢查，第 1 或第 2 層必須全部出現；漏一個就算失敗。這條可以寫成確定性測試，不靠 LLM judge。

**刻意不做**：TNM 分期推測、癌登院內碼、自由格式 markdown、通用「一份摘要給所有科」。

## 6. 待決問題（grill 清單）

1. **兩版是「初診／複診」還是「科別版／通用版」？** 我讀成前者＋科別是共同輸入。如果鄭 P 的意思是「有科別參數 → 科別版；沒有 → 通用版」，那是 2×2 = 四種，不是兩種。
2. **複診的「本科」判定**：健保申報科別碼分得出次專科嗎？分不出就只能到「內科」，心臟科複診會把新陳代謝科的就診也算進去。
3. **「相關科別最近檢查」的粒度**：每科最近「一次就診」、還是每種檢查各「最近一次」？後者對「沒看到之前檢查」的防漏比較有用，但會長。
4. **第 3 層「負責院所／科別」怎麼算**：最近一次開該診斷碼的院所？最近一次開該類藥的院所？兩者可能不同。
5. **家醫科要不要科別版**（§4.8）。
6. **住院版共用度**：華碩的住院 summary 是院內資料，我們是跨院；表單 J 欄能共用，但輸出不會是同一個產品。要不要在表單裡就明講？
7. **PROM 接法**：問卷結果要進 FHIR（QuestionnaireResponse）才吃得進來，還是先當文字附在 prompt？前者乾淨但要院方配合。
8. **時效窗誰定**：各科自填（表單 C 欄），還是先用 pack 裡現有的值當預設？
9. **科別多選**：一個醫師兩科（心臟＋一般內科）時，第 1 層用哪個？建議：URL 有帶用 URL，沒帶就跳一次選擇。
10. **表單載體**：Google Form／Excel／app 內建？app 內建的好處是填完直接變 config（§5 末段），壞處是 pilot team 要登入。
